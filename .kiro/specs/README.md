# .kiro/specs

Spec namespaces. Today only the genealogy platform spec lives here
(`genealogy-platform/`); future products would land under sibling
namespaces.

Each spec namespace MUST contain at minimum the documents listed in
`AGENTS.md` §1: `requirements.md`, `design.md`, `tasks.md`,
`ownership-catalog.md`, `architecture-decisions.md` and
`agent-execution.md`. Optional companions include persona maps,
journeys, scale/SLO, privacy/legal gates and a glossary.
