- Inherits the platform stack from `design.md` §1 (Kong, Keycloak, OpenFGA, Temporal, Strimzi, Apicurio, Istio, Vault/KMS, Flagsmith, Argo, Grafana stack). No new platform is introduced in this deliverable.

- Data residency matrix binds tenant onboarding to a single region; cross-region DR is only allowed within the same jurisdiction.
- Error budget burn-rate alert is parameterized with the Google SRE workbook windows (1h / 6h / 24h / 3d); privacy/DNA severity-1 freezes the budget unconditionally.
- No ADR-required decision was taken in this task. The 10 items in §11 are the explicit hand-off to E0.5, as required by `agent-execution.md` §2 "không tự chọn công nghệ ... cần ADR".
