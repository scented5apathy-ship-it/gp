## Decisions

- Owner rows name a **function/team**, not a single individual, per `architecture-decisions.md` §C #3 (RACI assignment). Individual + escalation is recorded in `runbook/<service>.md`; this catalog documents the contract.
- Synchronous dependency budget is codified per component (§4.2). DNA service is `n_sync = 0` because ADR-E0.5-15 keeps the module default-OFF and `privacy-and-legal-gate.md` §6 forbids raw DNA from crossing trust zones; any exception requires ADR reopen per §4.4.
- Compatibility / deprecation windows: REST **12 months**, gRPC **9 months**, Kafka event topics **6 months** with consumer opt-in window per topic `compat/<topic>.yaml`. These align with `design.md` §1 (RFC 9457 + ETag + idempotency), ADR-E0.5-08 (Apicurio BACKWARD) and ADR-E0.5-01 (pinned baseline + Renovate).
- RACI uses the conventional A/R/C/I split. Security remains accountable for threat model, vulnerability SLA and SBOM/Cosign per `requirements.md` NFR1 + NFR5 + ADR-E0.5-13. Privacy (DPO) remains accountable for DPIA, lawful basis, retention evidence, jurisdiction sign-off, breach SLA and pseudonymous label rotation per `privacy-and-legal-gate.md` §14 + §15.
- dna-service is on Tier-0 on-call with privacy-secondary dual escalation, matching the strict availability + integrity requirement of `design.md` §12 and the `scale-and-slo.md` §5.4 rule that any DNA privacy finding freezes release.
- Each service points to `runbook/<service>.md` and a Grafana dashboard / alert rule file; the runbook skeleton is in §7.1 and is generated by the Spring Boot template (E1.4) and Next.js template (E1.5).
- Open questions from `architecture-decisions.md` §C absorbed:

  - #4 (Cost model for Kong Enterprise / Temporal Cloud / commercial fallbacks) — out of scope for E0.6 (crosses into ADR-E0.5-04/07/14 lifecycle and E14 cost model) and tracked separately.
  - #6 (Pseudonymous tenant-label rotation cadence) — referenced in §7 #5 + §6.5 row and remains `quarterly DRAFT` per `architecture-decisions.md` §A.
