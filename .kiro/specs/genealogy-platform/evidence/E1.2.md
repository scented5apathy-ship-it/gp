## Decisions

- **ESLint flat config over `.eslintrc`.** ESLint 9 retired the old
  config format. Flat config aligns with ADR-E0.5-01 (Node 22 LTS,
  ESLint 9.13) and lets downstream packages extend the root config
  by `import base from "@genealogy/eslint-config"`.
- **No `eslint-plugin-yml`.** The plugin's rule namespace changed
  between 0.x and 1.x; rather than chase the version skew we ship
  `scripts/lint-yaml.mjs` which has the same intent (tabs,
  indentation, sensitive keys) and is the single source of truth
  for both CI and editor integrations.
- **Spotless staged for E1.6.** The `com.diffplug.spotless` plugin
  is only served from the Gradle Plugin Portal, which is not yet
  mirrored for every developer workstation. The convention script
  carries the apply block commented out so flipping the switch is
  a one-line change once E1.6 wires the supply-chain mirror. The
  Checkstyle gate (`./gradlew checkstyleMain checkstyleTest`)
  closes the immediate "Java code style is enforced" acceptance
  criterion.
- **Type-checked ESLint rules are off.** `recommended-type-checked`
  requires every linted file to belong to a `tsconfig.json`
  project. The root lints `.mjs` scripts under `scripts/` and
  `tools/` which do not. The strict type-check rules live inside
  each package's own `pnpm typecheck` step (which uses the
  package's own `tsconfig.json` and `tsc --noEmit`).
- **JDK 21 fallback in `run-gradle.mjs`.** Gradle 8.10's embedded
  Kotlin DSL bootstrap is incompatible with JDK 25 (IllegalArgumentException
  "25.0.4"). The wrapper forces `JAVA_HOME=JDK 21` so the
  developer experience is one command (`pnpm ci:quality`) and CI
  does not need a separate `JAVA_HOME` line.
- **Ownership-coverage script accepts files.** The original E1.1
  matrix declared `config/teams.yaml` and the `.github/` directory;
  the script was extended so declared paths can be either files
  (config files) or directories.
