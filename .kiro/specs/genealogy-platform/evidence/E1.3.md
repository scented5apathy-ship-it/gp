## Decisions

- **Avro over Protobuf for Kafka events.** ADR-E0.5-08 already
  picks Avro + Apicurio; the event schemas under `contracts/events/`
  follow that decision. Protobuf stays for internal gRPC per
  `design.md` §7.2.
- **YAML parser in `scripts/test-contracts.mjs`.** Avoids pulling in
  a 1 MB dependency just to read ~30 files. The parser handles maps,
  sequences, scalars, block scalars (`|`, `>`), and the `$ref` keys
  that OpenAPI documents require. It is intentionally narrow and
  rejects nothing — the assertions are the contract.
- **Spectral CI gate is best-effort defence in depth.** Spectral
  6.14 does not support `functionOptions.not.match`, so the
  authoritative DNA / raw / token check is the Node contract suite
  and the JUnit `ContractInvariantsTest`. Spectral still catches
  malformed OpenAPI documents before the contract suite runs.
- **Tenant context is server-derived.** Both the OpenAPI specs
  (`scripts/test-contracts.mjs` test #10) and the protobuf
  `common/v1/context.proto` enforce the rule that no client may
  supply `tenantId` / `idempotencyKey` in a request body. The BFF
  injects the trusted context into the gRPC call.
- **Buf config delivered ahead of `buf` install.** E1.6 wires the
  supply-chain mirror alongside SBOM + Cosign; the `buf.yaml` /
  `buf.gen.yaml` already in place mean the gate can be enabled
  with a single line change (no contract drift).
- **`x-versioned-resource: false` extension.** Used by the BFF
  session `selectTenant` endpoint where the mutation is not on a
  versioned aggregate. Documented in `contracts/openapi/README.md`.
- **Java contract tests live in `tenant-service`.** The Gradle
  `ContractInvariantsTest` walks the `contracts/` tree directly so
  the gate runs even before generated stubs are wired (E1.4).
  E1.6 will move it to a dedicated `contracts/contract-tests`
  module if multiple services need to share it.

## Security and privacy

- Tenant isolation: PASS — server-derived tenant context is
  enforced by both the OpenAPI contract (`scripts/test-contracts.mjs`
  test #10) and the protobuf `common/v1/context.proto`. No
  contract lets a client supply `tenantId` in a request body.
- Authorization/ABAC: N/A — no domain logic ships in this task;
  E3+ wires OpenFGA + ABAC. The contract types already declare
  `role` / `status` fields so the ABAC layer can plug in without
  breaking changes.
- Secret/PII/DNA leakage: PASS — every contract artefact rejects
  the forbidden DNA / raw / token field names via the Node
  contract suite, the Java `ContractInvariantsTest`, and the
  Spectral `forbidden-properties` rule. The Avro event envelope
  references `payload` as Avro bytes so the schema is enforced
  by the compatibility checker, not by JSON.
- Dependency/config scan: PASS — all new tooling is the same
  Apache-2.0 / MIT / MPL-2.0 stack already pinned in E1.1/E1.2;
  no AGPL added on the SaaS control plane. Renovate
  `vulnerabilityAlerts: enabled` carries the supply-chain gate
  until E1.6 wires SBOM + Cosign.
- License discipline: PASS — see above.

## Residual risks

- Spectral 6.14 does not support `functionOptions.not.match`. The
  authoritative DNA / raw / token check is the Node contract suite
  and the JUnit `ContractInvariantsTest`. Spectral still catches
  malformed OpenAPI documents before the contract suite runs.
  E1.6 introduces the Apicurio + `buf` compatibility toolchain so
  the gate can move from structural to compatibility-correct.
- The struct check for `scripts/lint-protobuf.mjs` runs when `buf`
  is not on `PATH`. `buf.yaml` + `buf.gen.yaml` are committed so
  the upgrade is a one-line change in E1.6.
- The BFF `selectTenant` endpoint uses `x-versioned-resource: false`
  to opt out of the `If-Match` rule. The BFF session itself is not
  a versioned aggregate; the BFF persists the selection server-side
  with its own concurrency control. Documented in
  `contracts/openapi/README.md`.
- The protobuf contracts do not yet carry generator output for Java
  modules — generation lands with E1.4 (Spring Boot template) so
  the Gradle plugin can be wired once. The contract suite
  intentionally parses `.proto` files directly so the gate runs
  today.
