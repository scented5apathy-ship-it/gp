## Decisions

- **OpenAPI codegen output lives under `apps/web/src/lib/api/generated/`**
  chứ không phải `packages/api-client/src/generated/`. Lý do:
  generated types chỉ được web shell consume (Java services dùng
  Spectral/protoc; BFF implement contracts mà không cần typed
  client shell-side). Tránh duplicate output + cross-package
  file dependency vi phạm AGENTS.md §2.7.
- **Skip `@radix-ui/*` ngay**. E6 sẽ swap Button/Card sang Radix
  variants khi editor milestone cần dropdown/dialog primitives.
  Hiện tại shell foundation chỉ cần Button + Card.
- **ICU MessageFormat deferred to E12.3** (per placeholder note
  trong `packages/i18n/src/index.ts`). Locale loader chỉ làm
  dotted-key resolution + `{name}` interpolation + fallback chain.
  RTL dirs được documented trong `localeDirection` map sẵn cho
  E12.3 land thêm (`he`, `ar`, …).
- **Test runner = Node `--test` (node:test)**. Không Jest/Vitest
  trong shell foundation. Wrapper `scripts/test-ts.mjs` xử lý
  TypeScript strip-types + extensionless resolver. Cùng pattern
  với các package khác.
- **Bundle budget = 220 kB First Load JS** (chỉ đếm route-specific
  chunks, lọc `static/chunks/*` framework). Build report Next 15.0.3
  cho `[locale]` home route ~109 kB First Load JS — well within
  budget. E6 sẽ tighten xuống ~150 kB khi editor/upload surfaces
  land.
- **`next.config.mjs` không emit CSP** — placeholder đã ghi nhận
  tại `.well-known/security.txt`. Lý do: CSP chặn Next.js dev
  HMR + future workbox SW; production rollout đi cùng service
  worker (E6). HSTS + X-Frame-Options + X-Content-Type-Options
  + Referrer-Policy + Permissions-Policy **đã bật ngay từ E1.5**.
- **CSP strict-dynamic deferred to E6** — chờ `next/script` worker
  pattern + service worker registration để hash inline scripts
  reliably.
- **PWA service worker deferred to E6** — `manifest.webmanifest` +
  icons + `display_override` đã sẵn sàng; SW đi kèm offline queue
  + IndexedDB (R17) và tree layout worker (§10.2). E1.5 chỉ ship
  app shell.

## Residual risks

- **No service worker yet** (R17 PWA offline mode) — `next-pwa`
  hoặc `@serwist/next` sẽ land trong E6 cùng offline queue +
  IndexedDB payload (R17). Hiện tại chỉ có manifest + icons +
  HTTPS-only display modes.
- **CSP deferred to E6** — `.well-known/security.txt` documents
  the future policy. Headless security headers đã on; full CSP
  đi kèm service worker registration.
- **No `@radix-ui/*` primitives** — Button/Card đủ cho foundation;
  editor/upload dropdowns/dialogs/tooltips sẽ swap sang Radix
  variants ở E6.
- **No Playwright/axe E2E** — accessibility + cross-browser E2E
  tests sẽ land ở E6 với editor milestone (per R18 + NFR7).
- **Inline `type` modifier trong import statements** — Node 24's
  `--experimental-strip-types` does not strip inline `type`
  modifiers. Refactored tất cả `import { Foo, type Bar }` sang
  `import { Foo }` + `import type { Bar }` để tương thích với
  Node 22 LTS (project target). Một số third-party tooling
  (e.g. `tsx`) có thể accept inline type; pin lại Node 22 LTS
  cho CI để giữ convention.
- **Custom Node ESM loader** (`scripts/ts-loader.mjs`) chỉ cần
  thiết cho `node --test`. Production Next build không cần
  loader (Next tự compile TS). Loader không can thiệp bare /
  absolute specifiers.
- **`X-Tenant-Id` runtime check** — runtime honours
  constructor/caller-supplied tenantId; full tenant predicate
  + ABAC + RLS enforcement is domain-layer concern (E3+).
