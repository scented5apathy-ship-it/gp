## Decisions

### `pnpm-workspace.yaml` keys

The Semgrep `pnpm/pnpm-missing-minimum-release-age` rule requires
the value as a literal minute count (10080 = 7 days), not the
string form (`"7 days"`) that Renovate accepts. The script
`scripts/security-ci.mjs` keeps both forms in sync: `min-release-age=7`
in `.npmrc`, `minimumReleaseAge: 10080` in `pnpm-workspace.yaml`,
`minimumReleaseAge: "7 days"` in `renovate.json`.

### `.trivyignore` baseline

The first scan of the repo surfaced 67 HIGH/CRITICAL CVEs across the
pinned Spring Boot 3.3.4 / Spring Framework 6.1.13 / Jackson 2.17.2 /
Netty 4.1.113 / Next.js 15.0.3 stack. Every CVE is listed in
`.trivyignore` with:
- expiry date ≤ `2026-09-30` (≤ 90 days from E1.6 close)
- owner team (`@genealogy/platform`, `@genealogy/web`)
- rationale = the ADR-E0.5-01 follow-up bump

The security team reviews the list weekly. The first run after
E1.6 evidence must show a shrinking list — every removed entry is a
patch that landed through Renovate. The gate fails automatically
once an entry expires without renewal.

### `trivy-sbom` + `grype` are advisory

Syft emits CycloneDX with `file`-typed components (manifest files,
build descriptors). Trivy-sbom cannot decode those (it bails out
with `failed to parse root component`). Grype handles them but
reports a different CVE set than Trivy-fs because of mirror
freshness, which would race the production gate. We keep the
blocking gate as `trivy-fs` + `.trivyignore`. The SBOM is still
produced and re-scanned in advisory mode; production image
verification (E15.1) uses `trivy image` against the signed
container, not the SBOM.

### Cosign keyless

`scripts/cosign-sign.mjs` defaults to `--keyless` (Fulcio +
Rekor). CI sets `COSIGN_OIDC_TOKEN` from the GitHub Actions OIDC
exchange. Local developers either reuse `--keyless` against the
public Sigstore (development certificates), or pass `--key` with
a key generated by `cosign generate-key-pair`. Private keys never
appear in `security/artifacts/`.

### Renovate review policy

`automerge: false` is the default for every `packageRules` block
except the patch-only auto-merge for tooling dependencies
(`@stoplight/spectral-cli`, `@eslint/js`, `eslint-config-prettier`,
`markdownlint-cli2`, `rimraf`, `typescript-eslint`). Major and minor
updates for runtime packages (Spring, Next.js, React, Node, TypeScript,
pnpm, Turbo, ESLint, Prettier) ALWAYS require manual review by
`@genealogy/platform` + `@genealogy/security`. Renovate opens a PR;
the security CI gate must pass; the GitHub `dependencyDashboard`
must be approved by an assignable reviewer. The
`vulnerabilityAlerts` channel creates a HIGH-priority PR with
`@genealogy/security` auto-assigned, but the merge still requires
the gate to be green.

### Why not Trivy-IaC as the blocking IaC gate

Checkov has the more comprehensive Kubernetes / Helm / Dockerfile /
Terraform ruleset, with finer-grained skip semantics per
`security/checkov/.checkov.yaml`. Trivy-IaC runs alongside as
defence-in-depth; both must agree on a finding before it's flagged.

## Residual risks

- **Cosign keyless requires internet access to Fulcio + Rekor.**
  Air-gapped on-prem deployments need to override
  `COSIGN_KEYLESS_OCI_FULCIO_URL` and `COSIGN_REKOR_URL` to the
  in-cluster SigStack (E14.3 wires this).
- **No SBOM stored long-term.** E1.6 uploads the SBOM as a
  90-day GitHub Actions artefact only. Long-term SBOM retention
  is owned by E14.1 (Backup matrix).
- **Trivy / Syft / Grype network rules** — every scanner image
  pulls the CVE database at run time. CI caches it under
  `~/.cache/trivy/` and `~/.cache/anchore/` for 7 days; on-prem
  must mirror the upstream registries.
- **`license-check.mjs` is deny-list only.** The script catches
  the forbidden licences but does not enforce the allowed set
  on the Gradle side. The full bidirectional check lands in
  E15.1.
- **Initial `.trivyignore` is long.** 67 CVEs across the pinned
  Spring Boot / Spring Framework / Jackson / Netty / Next.js
  stack. Each entry has an explicit owner + 90-day expiry; the
  security team reviews weekly. If the list does not shrink,
  the platform team is not delivering the ADR-E0.5-01 follow-up
  bumps and that becomes a release blocker.
- **`apps/web/src/app/error.tsx` keeps `console.error`** — the
  Semgrep rule excludes Next.js App Router boundary files because
  they render before the React tree mounts; the browser-side OTel
  auto-instrumentation (E13.1) re-ships the log. A future E6
  replacement can swap to the shared `platform-telemetry` logger.
- **`license-check.mjs` flag `internal`** — only forbidden
  licences block CI; an MIT package that pulls an AGPL
  transitive runtime dependency does NOT currently fail the
  gate. The transitive check lands in E15.1 once the SBOM-based
  licence mirror is wired into the supply-chain verification
  pipeline.
