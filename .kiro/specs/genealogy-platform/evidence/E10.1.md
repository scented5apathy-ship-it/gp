## Residual gaps

The architecture gate is blocked by ADR-E0.5-15 closure. The following open questions MUST be resolved before E10.1 can flip to `[x]`:

1. **DNA file format allowlist.** Which raw / match / segment / estimate formats are authorised for the release jurisdiction? Currently the contract declares the closed set (`CSV_ANCESTRYDNA`, `CSV_TWENTY_THREE_AND_ME`, `CSV_MYHERITAGE`, `CSV_FAMILY_TREE_DNA`, `FASTQ_ILLUMINA`, `BAM_ILLUMINA`, `VCF_GENEVA`, `VCF_ANCESTRY`), but the ADR has not signed off on the allowlist + provider matrix (ANCESTRYDNA / 23ANDME / MYHERITAGE / FTDNA / LIVING_DNA / SELF_UPLOAD_PROVIDED / RESEARCH_PARTNER).
2. **Matching algorithm approval.** `IBD_SEGMENT_V1`, `IBD_SEGMENT_V2`, `IBD_SEGMENT_V2_OPAQUE`, `KINSHIP_ESTIMATE_V1`, `KINSHIP_ESTIMATE_V2_OPAQUE`, `RELATIVE_DISCOVERY_V1` are the closed-set vocab in `dnaMatchAlgorithms`; the ADR must confirm algorithm version + jurisdiction compatibility (US `GINA_FEDERAL`, FL `GINA_FLORIDA`, IL `GIPA_ILLINOIS`, EU `GDPR_ART_9_2_G_SUBSTANTIAL_PUBLIC_INTEREST`, CA `CCPA_CPRA_SENSITIVE_PI`).
3. **Release jurisdiction allowlist.** `IsolationContext.jurisdictionAllowlist` is the only place where jurisdiction gating is enforced; ADR-E0.5-15 must declare the production allowlist and the residency cluster mapping (see `privacy-and-legal-gate.md` §3 + DPIA D-08).
4. **Guardian workflow jurisdiction matrix.** R13.8 + DPIA D-05 require a per-jurisdiction guardian workflow for minors + incapacitated subjects; `consentSubjects.GUARDIAN_ON_BEHALF_OF_MINOR` + `GUARDIAN_ON_BEHALF_OF_INCAPACITATED` + `COURT_APPOINTED_REPRESENTATIVE` already exist in `consentSubjects`, but the legal-effect mapping is open.
5. **Self-hosted raw-genotype interpreter ban.** Per `privacy-and-legal-gate.md` §14 #2, ADR-E0.5-15 must explicitly prohibit a self-hosted genotype interpreter and any medical interpretation engine; the E10.4 contract enforces this as a forbidden capability, but the ADR wording is the source of truth.
6. **Self-test capabilities for legal hold + retention.** `dnaExportRetentionPolicies` (SINGLE_DOWNLOAD / TIME_BOXED / LEGAL_HOLD_BLOCKED / IMMEDIATE_REVOKE) is declared, but the per-jurisdiction retention floor (currently 2 years / `CONSENT_RETENTION_SECONDS = 63072000`) and the legal-hold override rules require ADR sign-off.
