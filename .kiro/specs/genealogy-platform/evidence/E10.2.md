## Decisions

- ADR-E0.5-15 — DNA module is opt-in / default off; the contract-side guardrail `guardRails.featureFlagDefaultOff=true` and `DnaIsolationGuard.legalDnaEnabled` are the runtime gate. ADR-E0.5-08 BACKWARD is the compatibility policy.
- Sandbox egress allowlist = `[postgres-dna, vault-agent-dna, s3-dna, openfga-dna, audit-service, kafka-dna, temporal-frontend-dna]` — DNA-bucket-bound sidecars only, no shared endpoints with media / search / importexport.
- `treeViewerBypass` is a new forbidden payload key (`DnaForbiddenPayloadKeys`) to prevent tree roles from being reused as a covert DNA access path.
