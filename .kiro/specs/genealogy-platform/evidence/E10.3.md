## Decisions

- ADR-E0.5-08 BACKWARD for compatibility policy.
- Re-authorization MUST happen at activity time (not just submit time) per R13.3 + `privacy-and-legal-gate.md` §9 D-05; the closed-set guard rails enforce this on every grant / revoke / reauthorize / export / deletion / access.
- Consent ledger is append-only; mutation is impossible by design (capability boundary).

- Step-up auth is required for export / portability / deletion purposes (`DNA_EXPORT_RAW`, `DNA_EXPORT_MATCHES`, `DNA_PORTABILITY_REQUEST`, `DNA_DELETION_REQUEST`).
- Guardian workflow is mandatory for `GUARDIAN_ON_BEHALF_OF_MINOR` + `GUARDIAN_ON_BEHALF_OF_INCAPACITATED` + `minorFlag=true`.
