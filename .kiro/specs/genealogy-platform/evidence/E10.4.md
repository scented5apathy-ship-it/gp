## Decisions

- Per ADR-E0.5-15 the closed-set `dnaProviders` (7) and `dnaFormats` (8) are wired; runtime enablement is the E10.1 gate.
- Quarantine TTL = 1 hour; envelope decrypt timeout MUST finish within `quarantineTtl / 12` (300s ≤ 3600s / 12). The contract enforces this numeric invariant.
- Worker pool isolation: every raw-upload / matching request MUST carry the 4 DNA node-pool labels and one of the 4 DNA task queues.
- Algorithm version is exposed only as opaque label (max 64 bytes); no algorithm internals in payload / log / trace.
- Raw DNA / raw genotype / raw allele list / raw SNP table / raw segment summary / raw cM estimate / raw algorithm trace are all in the forbidden payload catalogue; `rawDnaPayloadBytesAllowed = 0` is the numeric invariant.
- Cross-region matching requires jurisdiction + residency check (`crossRegionMatch + !jurisdictionResidencyChecked` → `DNA_MATCH_WORKER_POOL_VIOLATED`).
- Segment thresholds: `minSnps >= 71 × minCentimorgans` (500 ≥ 71 × 7); segments-per-kit ≥ 50 × kits-per-request.
