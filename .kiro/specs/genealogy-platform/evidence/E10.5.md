## Decisions

- ADR-E0.5-08 BACKWARD for compatibility policy.
- Revoke propagation deadline = 5 × termination grace (300s ≥ 5 × 60s); every revoke job MUST terminate in-flight matches / uploads / sharing links + purge derived data + delete raw + emit evidence.
- Export requires step-up auth (`DNA_REVOKE_STEP_UP_AUTH_REQUIRED`); signed URL TTL MUST be ≥ 120 × revocation propagation (3600s ≥ 120 × 30s); bundle MUST carry DNA_DEFAULT_OFF / LIVING_ONLY / MINOR_ONLY / LIVING_AND_MINOR / SENSITIVE_FULL redaction.
- Evidence MUST set `evidenceExcludesDeletedContent` flag explicitly; otherwise `DNA_REVOKE_EVIDENCE_INCOMPLETE`.
- Legal-hold override is required only for `JURISDICTION_BAN_TRIGGERED`, `PROVIDER_TERMINATION_TRIGGERED`, `ADMIN_REVOKE_WITH_LEGAL_APPROVAL`; default behaviour blocks deletion while legal hold is active.
- Hard-delete timeout MUST be ≤ retention / 105120 (10 years → 600s ≤ 31536000s / 105120); the contract enforces this numeric invariant.
- Compensation actions MUST be a subset of the closed-set; raw DNA / raw segment / raw consent / raw ID / raw signature refused in evidence payload.
