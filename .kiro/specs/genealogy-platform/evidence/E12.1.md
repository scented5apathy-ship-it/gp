## Decisions

- Mirrored the `lint-notifications.mjs` pattern: closed-set vocabs +
  state matrices + invariants + capability boundaries (helper surface).
- `cacheableResources` uses `entries:` (object-form) instead of
  `values:` because the parser handles complex sequences more
  reliably than dotted entries.
- Forbidden URLs (`postgres://`, `https://hooks.slack.com/services/`)
  replaced with safe markers (`postgres-protocol-marker`,
  `slack-webhook-marker`) because the YAML parser splits on the
  first `:` inside quoted strings; the marker keeps the closed-set
  intent while staying parseable.
- `purgeDebounceMs` on PERMISSION_VERSION_BUMP only — other triggers
  require immediate eviction to prevent tenant/version drift.
- `cacheableTiers` collapsed into the `cacheTiers` vocab (single
  source of truth) — the per-stateTier logic lives in
  `classificationContext.allowedTiers` at runtime.
