## Decisions

- Plural category selects per locale (vi/ja/th→other, ru/pl/uk→
  one/few/many, ar→zero/one/two/few/many/other, fr/de/es→one/other,
  default→one/other).
- Locale fallback chain uses en as default base; pseudolocales
  are blocked at the boundary (already enforced by
  `lint-a11y-i18n`).
- Calendar conversion is intentionally approximate (Gregorian
  equivalence for Julian / Hebrew / Islamic / Ethiopic / Saka);
  the registry keeps the original calendar id on every entry
  so the consumer can round-trip display.
- DST detection uses wall-clock instant vs preferredOffsetMinutes;
  gap ≥ 60min offset difference is rejected.
- Glossary applies token→value substitution before send across
  email/PDF/report pipelines (R18.7 invariant).
