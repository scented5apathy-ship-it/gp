## Decisions

- HMAC-SHA256 keyed by Vault-managed pepper (90-day rotation) is the pseudonym algorithm. Output 16 bytes truncated to hex (32 chars).
- `circuitBreakerThreshold = 5`, `circuitBreakerWindowSeconds = 30`, `ringBufferMaxBytes = 4194304` (4 MiB) per NFR5 + E2.10 OTel Collector overflow baseline.
- IPv4 regex MUST run before phone regex so the phone regex cannot swallow the dotted-decimal IP (E12 + this contract).
- `oidc_subject` is FORBIDDEN as a plain label; only `actor_pseudo_id` (HMAC-SHA256) is allowed.
