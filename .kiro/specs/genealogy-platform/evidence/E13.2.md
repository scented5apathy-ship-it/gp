## Decisions

- Burn-rate alert thresholds per Google SRE workbook: 1h × 14.4x page, 6h × 6x ticket, 24h × 3x review, 3d × 1x silent trend. PII redaction coverage uses a 10m × 1x window because the failure mode is immediate and must page on-call.
- SEV1 freezes release + freezes error budget. Privacy / DNA / consent findings (4 closed categories) freeze budget immediately regardless of burn-rate (NFR7 + ADR-E0.5-16).
- Every alert rule MUST declare the 6 `requiredAlertRuleFields` keys AND the 7 `requiredAlertAnnotations` keys. The linter fails closed if any rule is missing a field.
- Synthetic probes cover the 10 platform components (Kong / Keycloak / OpenFGA / Postgres / Kafka / Temporal / Object Storage / Vault / Flagsmith / OTel Collector). 2-minute failure → SEV2 page.
- Cardinality ceiling (50K tenant / 200K user) enforced at the recording-rule layer; dimensions beyond the ceiling emit `telemetry.label.cardinality.exceeded` and are dropped.
