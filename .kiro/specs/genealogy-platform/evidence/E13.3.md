## Decisions

- k6 / Gatling is the load generator (no custom load runner); the harness MUST report p50 / p95 / p99 latency, error rate, RPS, payload size.
- HPA MUST use one of the closed-set metrics; manual scaling in production is FORBIDDEN.
- Connection pool ceilings: postgres 75, kafka producer 200, consumer 400, grpc 500, redis 600, temporal 100. Exceeding any trips a SEV3 alert.
- Kafka partition rule = `1 partition per 1 000 sustained RPS`, ceiling 256 partitions per topic.
- Temporal worker rule = `1 worker per 50 concurrent workflows`, ceiling 100 concurrent per worker.
- Core Web Vitals budget: LCP 2 500 ms, CLS 0.1, INP 200 ms, TTFB 800 ms, TTI 2 500 ms, TBT 200 ms.
- Regression gate: 10 % p95 / 25 % errorRate / 15 % throughput / 5 % bundle. Any trip aborts the canary via `Argo Rollouts` `abortOnErrorBudgetBurn`.
- Synthetic dataset locales cover Gregorian + RTL + CJK (vi-VN / en-US / fr-FR / ar-SA / he-IL / ja-JP / zh-CN).
- Synthetic datasets MUST carry `SYNTHETIC_ONLY` marker and MUST NEVER embed real PII or DNA (real-DNA rejection is enforced by `CapacityGuard.validateSyntheticDataset`).
