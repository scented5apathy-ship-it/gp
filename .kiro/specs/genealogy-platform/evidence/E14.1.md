## Decisions

- ADR-E0.5-04 (Kong runtime) — not involved; backup is a
  platform-side concern, Kong holds runtime edge policy.
- ADR-E0.5-06 (OpenFGA) — model + tuple backup must use
  `openfga_store_export` only; no custom export.
- ADR-E0.5-07 (Temporal) — temporal backup uses
  `temporal admin cli export`; per ADR-E0.5-07 we do not
  fork the Temporal workflow engine.
- ADR-E0.5-08 (Kafka/Apicurio) — Kafka backup uses Strimzi
  operator backup; we do not reimplement a schema snapshot.
- ADR-E0.5-12 (Vault / KMS) — every backup artefact MUST be
  encrypted by Vault KVv2 + transit; cross-tenant custody
  forbidden.
- E13.2 SLO contract — RPO ≤ 900 s for `postgresql` and
  `object_storage` (15 min), ≤ 3 600 s for `kafka` (1 h),
  ≤ 86 400 s for everything else (24 h); RTO ≤ 14 400 s
  (4 h) globally per NFR3 baseline.
