## Decisions

- **Provider-neutral application contract.** Domain code
  binds to `com.genealogy.platform.featureflags.FeatureFlagClient`
  (Java) and `@openfeature/js-sdk` (Node.js / Next.js PWA).
  The Spring Boot starter
  `OpenFeatureAutoConfiguration` installs the `NoOpProvider`
  as the safe default; the Flagsmith provider is wired via
  the `platform.openfeature.provider=flagsmith` property.
- **Self-hosted Flagsmith on on-prem + dev; managed
  Flagsmith SaaS on SaaS.** Per `tasks.md` E2.8 +
  `design.md` §1 + ADR-E0.5-03, on-prem + dev use the
  upstream `flagsmith/flagsmith:2.139.4` image; SaaS uses
  managed Flagsmith SaaS (provider: `flagsmith-saas`). The
  chart's Flagsmith workload is bypassed on SaaS via
  `provider: flagsmith-saas`; the same source-of-truth
  files are shipped to the Flagsmith SaaS workspace via the
  IaC pipeline.
- **5 environments, 1 per deployment cluster (NOT per
  tenant).** Per `privacy-and-legal-gate.md` §12, a feature
  must be OFF for every tenant/environment until a condition
  in §3 / §4 / §5 / §7 / §8 / §9 is satisfied. Per-tenant
  overrides happen via Flagsmith segments
  (`segmentOverride: true`), NEVER via a per-tenant
  environment. The `audit` environment is read-only for the
  DPO + privacy team.
- **SDK safe-default rule is mandatory.** Every consumer
  reads the flag from OpenFeature SDK with a typed default.
  When Flagsmith is unreachable, the SDK MUST return the
  default — NEVER the inverse, NEVER `null`. The default
  value MUST match the `safeDefault` column in
  `flag-taxonomy.yaml`. The deep linter rejects any flag
  with `safeDefault: null`.
- **Forbidden flag patterns are rejected.** A flag that
  toggles `skip_auth` / `skip_openfga` / `skip_abac` /
  `skip_consent` / `skip_audit` / `bypass_auth` /
  `bypass_consent` / `disable_audit` / `disable_encryption` /
  `no_redact` / `raw_dna` / `raw_pii` is FORBIDDEN. The deep
  linter enforces this via regex on every flag key.
- **Evaluation context is scoped by `tenant_pseudo_id`.**
  The ABAC layer (E3.4) verifies the pseudo-id against the
  BFF-issued trusted context. The deep linter rejects a
  `safe-defaults.yaml` that drops `tenant_pseudo_id` from
  the required attributes or adds `tenant_id` to the
  forbidden attributes.
- **Bootstrap Job runs on every `helm upgrade`.** The
  `featureflags-bootstrap` Helm-hook Job ensures the 5
  environments + 4 RBAC roles + flag taxonomy are present.
  The `driftCheck` causes the upgrade to abort if the live
  Flagsmith environment drifts from the source-of-truth.
- **Resilience posture prevents amplification.** Circuit
  breaker (5 failures → 30s open → 2 success half-open),
  retry budget (1 attempt / 100ms backoff), bulkhead (100
  concurrent / onFull=safe-default). A flag fetch can never
  amplify at the mesh layer (per `design.md` §13).
- **Per-evaluation cache is 30s.** The Flagsmith server
  cache is 5s (low rollout latency); the OpenFeature SDK
  cache is 30s. A stale flag value is the canonical cause
  of a rollout regression; the 30s ceiling prevents
  cross-version inconsistency.

## Security and privacy

- **Tenant isolation: PASS.** Every evaluation context MUST
  carry `tenant_pseudo_id`; the ABAC layer (E3.4) verifies
  the pseudo-id against the BFF-issued trusted context. The
  linter rejects `tenant_id` / `user_id` / `email` /
  `raw_dna` in the evaluation context.
- **Authorization / ABAC: PASS — boundary enforced.**
  Flagsmith decides flag value only. Domain authorization
  (living / DNA / consent) stays in the destination service
  via OpenFGA + ABAC; the contract stub explicitly forbids
  business authorization in Flagsmith. Flags MUST NOT
  bypass authorization, consent, or audit.
- **Secret / PII / DNA leakage: PASS.** The deep linter
  rejects literal `password`, `apiKey`, `token`,
  `private_key`, `AWS_ACCESS_KEY_ID`,
  `AWS_SECRET_ACCESS_KEY` values. No raw DNA / PII /
  secret payload is stored in Git / Helm values /
  image / logs. Audit labels enforce
  `tenant_pseudo_id` only.
- **Anonymous access: PASS — FORBIDDEN.** Flagsmith MUST
  NOT run with `ALLOW_ANONYMOUS=true`. JWT auth + per-
  environment API tokens are mandatory.
- **Backing store: PASS — Postgres required.** In-memory
  backing store is FORBIDDEN in production / staging /
  on-prem; local dev uses the shared PostgreSQL service.
- **TLS: PASS — TLS 1.2 minimum.** The Kong policy (E2.2)
  enforces the same posture on the public edge.
- **Bootstrap drift check: PASS.** The
  `featureflags-bootstrap` Job aborts on any drift between
  the source-of-truth file and the live Flagsmith
  environment. Operators re-run with `--force` to
  overwrite OR update the source-of-truth file to match.
- **Forbidden flag patterns: PASS.** The deep linter
  rejects any flag key matching `skip.*auth` /
  `skip.*openfga` / `skip.*abac` / `skip.*consent` /
  `skip.*audit` / `bypass.*auth` / `bypass.*consent` /
  `disable.*audit` / `disable.*encryption` / `no.*redact` /
  `raw.*dna` / `raw.*pii`.
- **License discipline: PASS.** Flagsmith is BSD-3-Clause;
  OpenFeature SDK is Apache-2.0; Flagsmith admin UI uses
  React (MIT). No AGPL dependency is introduced.
