## Changes

### New — `libs/platform-security` (Java)

- `src/main/java/com/genealogy/platform/libs/security/abac/`
  - `AbacPolicyEngine` — interface (the seam every service
    depends on).
  - `DefaultAbacPolicyEngine` — reference implementation;
    mirrors `contracts/abac/policy.yaml`. 9-rule deny-first
    evaluation: suspended/soft-deleted → impersonation →
    GENETIC_RAW+support → GENETIC_*+consent → SENSITIVE+consent
    → minor+PUBLIC → minor+PRIVATE (allow + redact) → living+PUBLIC
    (allow + redact) → default allow + audit.
  - `AbacDecision` — `allow | deny` + reason code + obligations
    + evaluated-at + attributes + opaque `decisionId`. The
    `decisionId` is the audit / dashboard correlation key.
  - `AbacObligation` — `REDACT_FIELDS` / `WATERMARK` / `AUDIT`
    kinds; `RedactionProfile` (field name list), `WatermarkProfile`
    (label + visible), `AuditProfile` (action + before/after).
  - `ReasonCode` — 12 closed-set reason codes (additions require
    an ADR; the catalogue is the audit contract).
  - `AbacRequest` — read-only request view (the contract the
    engine consumes).
  - `AbacDecisionCache` — short-lived cache with explicit
    `invalidate` / `invalidateByPrefix` / `invalidateAll`. The
    TTL is the upper bound for emergency-only staleness (per
    ADR-E0.5-06); the cache MUST NOT be the source of truth.
  - `OpenFgaAbacGuard` — combinator that pairs an OpenFGA check
    with the ABAC overlay; closes the Semgrep rule
    `no-openfga-allow-without-abac` (E1.6). Short-circuits on
    OpenFGA deny with `OPENFGA_DENY`.
  - `PrivacyClass`, `LivingStatus`, `ConsentRecord`,
    `Jurisdiction` — closed-set value types used by the engine.
- `src/main/java/com/genealogy/platform/libs/security/redaction/`
  - `PiiRedactor` — field-level redactor; mirrors
    `contracts/abac/redaction.yaml`. `denyKeys` (dropped),
    `maskKeys` (`[REDACTED:<key>]`), `scrubPatterns` (email /
    SSN / token regex). Used by the platform-telemetry
    redaction filter and any service that needs field-level
    scrubbing before logging.
- `src/test/java/com/genealogy/platform/libs/security/...`
  - `DefaultAbacPolicyEngineTest` — 14 tests covering
    suspended / soft-deleted, impersonation, support session,
    GENETIC_DERIVED with revoked / expired / missing consent,
    SENSITIVE without consent, minor on PUBLIC (deny) /
    PRIVATE (allow + redact), living on PUBLIC (allow + redact),

  - `OpenFgaAbacGuardTest` — 4 tests covering OpenFGA-allow +

  - `AbacDecisionCacheTest` — 5 tests covering max-age

  - `PiiRedactorTest` — 6 tests covering deny keys dropped,

## Decisions

- ADR-E0.5-06 ("ABAC overlay in application code; OpenFGA only
  decides relationships") — followed verbatim. The
  `OpenFgaAbacGuard` combinator is the implementation side of
  the Semgrep rule.
- ADR-E0.5-01 ("ABAC overlay remains in application code") —
  followed; the engine ships in `libs/platform-security`, not as
  a managed service.
- `privacy-and-legal-gate.md` §DNA (D-01, D-05, D-06) — DNA
  consent checked at evaluate time; raw DNA in `DENY_KEYS`;
  consent revocation triggers cache invalidation.
- `privacy-and-legal-gate.md` §Support (R16.4) — support
  session cannot read GENETIC_RAW even with a valid consent
  record (the engine returns `JURISDICTION_BLOCKED`).
- `privacy-and-legal-gate.md` §Living / §Minor (privacy gate
  §7 P-01, P-02) — living fields redacted on public projection,
  minor records denied on public projection unless a guardian
  consent is recorded (DRAFT in the engine — explicitly denied
  by default per privacy posture).
- `agent-execution.md` §4.4 ("Config-first ... OpenAPI,
  Protobuf, Apicurio") — ABAC is config-first: the YAML
  contracts are the source of truth, the Java engine is the
  executor. The linter enforces structural parity.
- `Semgrep` `no-openfga-allow-without-abac` (E1.6) — the
  `OpenFgaAbacGuard` combinator is the canonical closure;
  unit tests cover the deny short-circuit.

## Security and privacy

- Tenant isolation: PASS — every ABAC decision is scoped by
  `tenantId` + `resourceType` + `resourceId`; the cache key
  prefix is tenant-bound; `invalidateTenant` wipes a tenant's
  decisions on suspend / soft-delete.
- Authorization/ABAC: PASS — the engine deny-first order
  enforces: impersonation cannot reach DNA, support cannot
  read GENETIC_RAW, GENETIC_* requires active consent, SENSITIVE
  requires consent, minor on PUBLIC is denied, living on PUBLIC
  is redacted. The `OpenFgaAbacGuard` ensures OpenFGA allow is
  always combined with ABAC overlay (Semgrep
  `no-openfga-allow-without-abac`).
- Secret/PII/DNA leakage: PASS — redaction lists mirror the
  privacy gate §11 forbidden classes; the runtime redactor
  drops `rawDna`, `raw_dna`, `dnaRaw`, `genotype`, `sequence`,
  `kitPayload`, `rawBytes`, `biography`, `freeText`, `notes`
  before any sink; email / SSN / token patterns are scrubbed
  from free-text values; the chart mirror + contracts are
  scanned for `password=`, `token=eyJ`, `dsn=jdbc:` literals
  (the linter would exit 1).
- Dependency/config scan: PASS — no new Gradle dependency
  added to any service; `libs/platform-security` declares
  `slf4j-api` only (no AGPL, no Semgrep rule violated); the
  Java toolchain is pinned to 21 (ADR-E0.5-01); no new Docker
  image introduced.
- Cross-service boundary: PASS — 11 services scanned, 0
  cross-service db/domain imports. `tenant-service.application`
  depends on `libs/platform-security` (cross-cutting library,
  allowed by AGENTS.md §2.7).
- Cache invalidation invariant: PASS — `cache.invalidationOnWrite:
  required` + `cache.ttlOnlyForbidden: true` in
  `contracts/abac/cache.yaml`; `MembershipCommandService.revoke`
  calls `abac.invalidateOnChange(...)` AFTER the row update;
  `TenantCommandService.suspend` / `softDelete` call
  `abac.invalidateTenant(...)` (privacy gate §6.4 T-07).
- Audit hook: PASS — every default `allow` carries an
  `AuditProfile` obligation; the audit hook (`platform-spring-boot-starter`)
  publishes a `AuditEvent` with `decisionId` + `reasonCode`
  + `engineId` so the on-call team can trace a denial back to
  the policy.

- [x] **Living / minor, privacy class, consent purpose,

  implements all 5 predicates; covered by 14 unit tests in

- [x] **Combine OpenFGA allow with ABAC obligations (redact,

  `invalidateOnChange`; `suspend` / `softDelete` →
  `invalidateTenant`. `AbacDecisionCacheTest` + `OpenFgaAbacGuardTest`
  prove the prefix / tenant semantics.

## Residual risks

- The ABAC engine in this epic is the in-process Java reference
  implementation. A future epic may add a managed policy service
  (e.g. OPA / Casbin); the `AbacPolicyEngine` interface is the
  seam. No migration is required when that change lands — the
  cache, enforcer and redaction all stay the same.
- The Semgrep rule `no-openfga-allow-without-abac` is a
  WARN-level check; if a service grows a new `openfga.check`
  call site that bypasses the combinator, CI fails the rule
  but the failure is logged as a warning today. E1.6 should
  escalate it to ERROR once the OpenFGA client ships and the
  combinator is the only sanctioned use site.
- `Jurisdiction.ROW` is the current default for the tenant
  row (E0.5-04 ADR closes the residency column). The engine
  still applies the suspended / soft-deleted / impersonation /
  DNA rules without a jurisdiction value — privacy posture is
  preserved.
