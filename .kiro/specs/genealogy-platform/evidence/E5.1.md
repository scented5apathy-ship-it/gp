## Decisions

- **Bench runs in Node 22 + `node:worker_threads`** (no
  Playwright / browser binary in CI) per `agent-execution.md`
  §4.4 scope-creep prevention. The real on-device profile
  lands in E5.3 with the tree projection API. The
  recommendation memo flags this as a documented limitation
  in every report.
- **Renderer options implemented as separate modules** under
  `apps/web/bench/renderer/` (Node-only) — never imported by
  the Next.js app. This honours "Duyệt ADR trước khi đưa
  library vào production" (ADR-E0.5-10 still `DEFERRED`).
- **Placebo renderer = 1K-node canvas** per ADR-E0.5-10
  §Consequences. No library choice made. `apps/web/package.json`
  `dependencies` unchanged.
- **Bundle-size proxy = serialized JS payload** (not webpack
  stats). Real `next build` bundle measured by
  `apps/web/test/perf-budget.test.ts` (E1.5) once E5.3 lands.
- **A11y + keyboard scores = heuristic** (1.0 best, 0.0 worst).
  Real Playwright + axe-core audit is E5.5 with the editor
  milestone.
- **Synthetic generator** seeded by
  `sha256(size + locale)` per `scale-and-slo.md` §3.3.
  On-disk cache gitignored under `bench/datasets/`.
- **ADR closure decision is NOT flipped**. The recommendation
  memo inside every report is **advisory only**; the closing
  decision remains owned by the Web lead + Performance lead
  per `architecture-decisions.md` ADR-E0.5-10 §Owner line 554.
- **Assumptions**: None — every threshold is pinned in the
  contract; every closed-set comes from the contract; the
  bench harness agrees with the linter on shape because
  they share the same loose YAML parser.

## Security and privacy

- **Tenant isolation**: PASS — bench operates exclusively on
  synthetic graphs generated locally from
  `sha256(size + locale)`. No real tenant data is read. Node
  payloads are opaque ids only (`person-<n>`, `tree-synthetic-1`,
  `tenant-synthetic-1`); `assertOpaqueId` enforces the pattern
  `^[A-Za-z0-9._:-]{1,128}$` at every renderer boundary so
  PII (email, phone) and DNA markers cannot leak into the
  output artefacts. `report.md` and `result.json` files
  contain no PII / DNA.
- **Authorization/ABAC**: N/A — bench does not exercise
  tenant-scoped data; the redacted projection lands in
  E5.3 (per documented limitation).
- **Secret/PII/DNA leakage**: PASS — linter scans the
  contract for the same forbidden literals as the rest of
  the platform linters (passwords, tokens, AWS keys, PEM
  blocks, JDBC credentials). No new external dep added to
  `apps/web/package.json`; existing dep set unchanged.
- **Dependency/config scan**: PASS — only `node:fs`,
  `node:worker_threads`, `node:crypto`, `node:url`,
  `node:path`, `node:os`, `node:child_process` (via spawn
  in the bench itself). All MIT-equivalent (Node builtins).
  No new `package.json` deps.
