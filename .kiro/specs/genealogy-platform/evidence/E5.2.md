## Decisions

- ADR-E0.5-06 "cache invalidation mandatory on every Write, TTL-only forbidden" — encoded trong `tree-projection-cache.yaml::spec.ttlOnlyForbidden: true` + `invalidationOnWrite: required` + `freshnessTtlSecondsCeiling` capped at 1800; Java `TreeProjectionCache` constructor rejects any TTL > ceiling.
- ADR-E0.5-06 / glossary-and-policy-matrix.md §11 — redaction obligations applied INSIDE `TreeProjectionBuilder` (genealogy-service) per "Persona redaction filters MUST run inside the service that owns the aggregate; the BFF only applies coarse formatting. Cross-service redaction is forbidden." BFF never re-applies redaction.
- Policy §2.1 Living — `ProjectionRedactionReasonCode.LIVING_REDACTED` drops displayName + contact + biography + birthYear when LivingStatus ∈ {LIVING, INFERRED_LIVING} AND PrivacyLevel ∈ {PRIVATE, UNLISTED}.
- Policy §2.2 Minor — `MINOR_GUARDIAN_REQUIRED` drops currentResidence / school / guardians / birthYear when Living + non-PUBLIC.
- Policy §2.7 Visibility Unlisted Token — `VISIBILITY_UNLISTED_TOKEN_INVALID` (driven by `ProjectionQuery::unlistedTokenInvalid`) drops displayName + birthYear for living persons.
- Privacy Class — `PRIVACY_CLASS_RESTRICTED` drops biography / genderDescription / freeText / notes when PrivacyLevel=PRIVATE; bucket filter marks the node with `redacted: true` instead of dropping it (cache key stability).
- Closed-set OPAQUE_ID_PATTERN `^[A-Za-z0-9._:-]{1,128}$` enforced cho mọi path/query param trong OpenAPI + schema validation trong policy.
- projection caching never source-of-truth: cache contract mandatory, but the read model is always rebuildable từ JDBC-backed store (production). In-memory store là executor cho unit tests + smoke profile.
- Vỉews mapping — view kinds trong policy khớp 1:1 với `ProjectionViewKind` enum + BFF OpenAPI enum. `locked: true` (pedigree, descendant) ngăn client override direction; `locked: false` (fan, hourglass, family) cho phép override.
- Cache key — `gp:{tenant_pseudo_id}:genealogy:projection:{treeId}:{viewKind}:{direction}:{depth}:{filterHash}`. Filter hash là hex của String.hashCode trên canonical sorted serialization. Mirror với `valkey-config.yaml::requiredUsers[genealogy-service].keys = "gp:*:genealogy:*"` — ACL range đúng.
- ADR-E0.5-10 (tree renderer) — E5.2 KHÔNG đụng renderer lib; chỉ cung cấp read-model + delta endpoint để E5.3 (Tree views) consume.
- Assumptions: None — mọi threshold pinned trong policy contract; mọi closed-set từ contract; cache contract mirror Valkey ACL config.

Cache key prefixed `gp:{tenant_pseudo_id}:`; ACL key pattern `gp:{tenant_pseudo_id}:genealogy:projection:*`. In-memory store is per-tenant implicit (TenantId on every record).
- Authorization/ABAC: PASS — redaction obligations applied INSIDE the service per glossary-and-policy-matrix.md §11. `ProjectionQuery::unlistedTokenInvalid` (default false) marks responses with `VISIBILITY_UNLISTED_TOKEN_INVALID`. BFF never re-applies redaction.

JSON schema is `additionalProperties: false` (root + metadata + spec). `RedactionSummary.droppedFieldCount` provides the audit ledger with the count of fields dropped; per-node `droppedFields` lists the closed-set of dropped keys.
