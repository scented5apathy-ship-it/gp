- **ADR-E0.5-01 (Java 21 toolchain): ACCEPTED** — `services/research-service/build.gradle.kts` now applies `java-conventions` + `service-conventions` (ArchUnit boundary guard).
- **No cross-service domain import** — `services/research-service/.../Certainty.java` is a *local* enum with vocabulary aligned to `genealogy-service` via the contract only. The ArchUnit boundary guard (wired through `service-conventions`) blocks accidental coupling (`pnpm check:boundary` → clean).
- **In-memory provenance executor only** — E6.1 vessels the executor in a tenant-indexed `Map<String, Map<String, …>>` triple. The Flyway migration + jOOQ repository + Kafka publisher land in E6.2+. The platform `ownership-catalog.md` makes this explicit (`Sync dep budget: n_sync = 0` read path).
- **E6.1 keeps the editor + UI out of scope** per `agent-execution.md` §4.4. Per the user's explicit choice on the §4.4 scope question, the implementation commits the domain + invariants + provenance query + linter + tests but defers the openapi.yaml, gRPC stubs, Flyway migration, Kafka producer/consumer and Vue / React components to the later E6.x sub-epics.
- **Audit metadata uses `actorPseudoId` only** — never raw user id / email / DNA. Mandated by `ResearchAuditAttributes` compact constructor + audit contract `auditActorKey: actorPseudoId` / `auditCorrelationKey: correlationId`.
- **Pointer-only sources** (`ARCHIVE` / `FINDING_AID`) require at least one attachment; the invariant service emits `SOURCE_POINTER_REQUIRES_ATTACHMENT` (DENY) when the constructor is bypassed (e.g. JDBC rehydration).
- **Hypothesis closure** — terminal status (`REFUTED` / `SUPERSEDED`) cannot transition out; this is enforced both by the state machine and by the invariant service (matrix validation in `lint-research-config`).
- **Confidence bounds** — `[0.0, 1.0]` pinned via `spec.confidenceMin` / `spec.confidenceMax`; NaN / Infinity rejected by `Confidence.requireInRange`.
- **No new dependency added** — `services/research-service/build.gradle.kts` keeps the existing `spring-boot-starter-actuator + postgres + flyway + openfeature` baselines; no new Maven coordinates.
- **Single source of truth** — the YAML contract under `contracts/research/` is the cross-service reference; the platform mirror at `platform/helm/genealogy-platform/files/research-policy.yaml` is byte-identical and enforced by the linter.

The provenance query is partitioned by tenant id; `traverse` for an unknown tenant returns an empty chain (test `traversableForUnknownTenantIsEmpty`).
- **Authorization/ABAC**: N/A — ABAC overlays living status, DNA, consent and contextual deny at the application layer (`design.md` §6.2). E6.1's domain layer captures the closed-set vocabularies (`Certainty`, `ResearchAuditAttributes.actorPseudoId`) that the application layer will key off. The ArchUnit boundary guard (per `service-conventions`) blocks accidental coupling to other services.
