## Decisions

- **ADR-E0.5-08 (Avro + Apicurio + BACKWARD evolution): ACCEPTED** — every closed-set vocabulary anchored to the YAML contract; the Java enum values are validated by the linter. Adding a new value requires an ADR supersession.
- **ADR-E0.5-01 (Java 21 toolchain): ACCEPTED** — `services/media-service/build.gradle.kts` applies the `java-conventions` + `service-conventions` plugins (Java 21, Checkstyle, ArchUnit boundary guard).
- **ADR-E0.5-06 (OpenFGA store-per-tenant, p95 ≤ 500 ms): ACCEPTED** — `DeliveryOpenFgaPort` is a pure port; the orchestrator calls it with `(tenantScopeId, assetId, actorPseudoId, subject)` and refuses to issue a signed URL if OpenFGA returns DENY. The ABAC overlay runs AFTER the OpenFGA verdict per `deliveryDenyBeforeOpenFgaAndAbac=true`.
- **ADR-E0.5-15 (DNA file formats + consent revocation): ACCEPTED** — `dnaBucketAccess=FORBIDDEN` enforces the closed-set `dnaBucketPrefixes=[dna/raw, dna/match, dna/consent]` BEFORE OpenFGA (per `MediaProtectedDelivery.authorize(...)` step 0); `revokePropagationSeconds=60` matches `glossary-and-policy-matrix.md` §2.8 + `CONSENT_REVOCATION_PROPAGATION_SECONDS=60`.
- **YAML contract is the source of truth** — the 15 closed-set vocabularies + the authorization state matrix + the 16 boolean guard rails + the 21 numeric bounds + the 16 invariant reason codes + the 5 audit hooks live in `contracts/media/media-protected-delivery-policy.yaml` and the helm mirror. The Java executor mirrors the contract; the linter enforces it.
- **Platform-component delegation (no re-implementation)** — the OpenFGA SDK + watermark worker + S3 / MinIO signed-URL issuer are pure ports (`DeliveryOpenFgaPort` + `DeliveryWatermarkPort` + `DeliverySignedUrlPort`). The implementation lands in the worker subproject (E7.x / E11.x); the chart NetworkPolicy + Vault Agent Injector + Istio mesh wiring are reused. Per `design.md` §1 + §3.1 + AGENTS.md §5.
- **Sandbox egress allowlist (E2.6 + E3.3 + E3.6 + E7.4)** — `sandboxEgressAllowlist=[apicurio, vault-agent, openfga, audit-service]`. The NetworkPolicy enforces the same allowlist at the cluster level. Per `design.md` §11 + AGENTS.md §3 (Istio handles workload identity / mTLS).
- **`deliveryLinkableStatuses=[DERIVED_READY]` is a hard invariant** — `MediaProtectedDelivery.authorize(...)` checks `objectReady` BEFORE any other gate; `objectReady=false` forces `DENY` with `OBJECT_NOT_READY`. The E7.3 linkability invariant carries through to E7.4; the linter enforces `spec.deliveryLinkableStatuses MUST equal ['DERIVED_READY']`.
- **DNA bucket shield** — `dnaBucketAccess=FORBIDDEN` + `dnaBucketPrefixes=[dna/raw, dna/match, dna/consent]`. `MediaProtectedDelivery.isDnaBucketKey(...)` refuses `objectKey.startsWith("dna/")` (and the three explicit sub-prefixes) BEFORE OpenFGA + ABAC; the orchestrator returns `REDACT` + `ABAC_DENY` + `DNA_BUCKET_DENIED`. The DNA service owns its own delivery path per ADR-E0.5-15 + `privacy-and-legal-gate.md` §5.
- **OpenFGA + ABAC both required** — `deliveryDenyBeforeOpenFgaAndAbac=true`. The orchestrator first checks membership / consent / tenant / policy-version revocation sources (short-circuit before OpenFGA), then calls OpenFGA, then applies the ABAC overlay (watermark + redaction). Both gates MUST pass before a signed URL is issued.
- **Living / minor require watermark** — `watermarkRequiredForLiving=true` + `watermarkRequiredForMinor=true`. The orchestrator consults the watermark port for the canonical mode: `LIVING → TEXT_OVERLAY`, `MINOR → DIAGONAL_REPEAT`, `HISTORICAL → NONE`. The overlay embeds `actorPseudoId` + request timestamp; raw user id / email / IP / DNA are NEVER embedded per `DELIVERY_PSEUDONYM_IN_AUDIT` invariant.
- **Idempotent authorization on `deliveryId`** — the orchestrator is deterministic and idempotent on `deliveryId` + request inputs; re-running the chain produces the same decision. The Temporal workflow uses `deliveryId` as the activity id.
- **Signed URL TTL ceiling (15 min)** — `signedUrlTtlCeilingSeconds=900` per E2.7 evidence (`media-service` / `import-export-service` TTL ≤ 15 min). The orchestrator enforces a conservative default of 5 minutes (300 s) for ALLOW / ALLOW_WATERMARKED / ALLOW_RANGE_ONLY. Lower bound is 15 s (clock skew + retry safety); `SignedUrlTicket.TTL_MINIMUM_SECONDS=15` + `SignedUrlTicket.TTL_CEILING_SECONDS=900` enforced in the compact constructor.
- **Range bounded + multi-range forbidden** — `rangeRequestMaxBytes=67108864` (64 MiB) + `rangeRequestMinBytes=1024` + `multiRangeRequestsForbidden=true` + `rangeRequiresContentRangeHeader=true`. The `RangeRequest` compact constructor enforces span ∈ [1024, 64 MiB]; `RangeRequest.parseFromHeader(...)` throws on multi-range (`bytes=0-100,200-300`).
- **Revocation propagation (60 s)** — `revokePropagationSeconds=60` per ADR-E0.5-15 + `glossary-and-policy-matrix.md` §2.8 + E2.7 evidence. The orchestrator short-circuits on `MEMBERSHIP_REVOKED` / `TENANT_DELETED` / `CONSENT_REVOKED` / `POLICY_VERSION_BUMPED` BEFORE OpenFGA; an in-flight signed URL whose `deliveryId` matches a revocation event is marked REVOKED within 60 s.
- **Object lock COMPLIANCE 30 d** — `objectLockComplianceDays=30` per E2.7 evidence; DNA-adjacent buckets use `COMPLIANCE` mode for 30 days.
- **Audit metadata uses `actorPseudoId` only** — never raw user id / email / IP / DNA / token. Mandated by the 5 audit hooks + the 10 audit class/action pairs in the E7.4 contract. The `WatermarkOverlay` compact constructor enforces `actorPseudoId` embedding in the overlay text.
- **No cross-service domain import** — the ArchUnit boundary guard (`ServiceBoundaryTest`) blocks accidental coupling to other services; `pnpm check:boundary` clean. The new `services/media-service/.../delivery/` package only imports from `services/media-service/.../domain/` (E7.2 PipelineStatus carry-through) — never from another service's `db/` or `domain/`.
- **Helm keys with `-` are parsed as subtraction** — per the E6.1e convention the chart uses `services.mediaDelivery` (no hyphen). The pipeline keys (`signedUrlTtlCeilingSeconds`, etc.) match the contract field names verbatim.
- **No new dependency added** — `services/media-service/build.gradle.kts` keeps the existing `spring-boot-starter-actuator + postgres + flyway + openfeature` baselines + the `archunit-junit5:1.3.0` transitive. No new Maven coordinates.
- **Single source of truth** — the YAML contract under `contracts/media/media-protected-delivery-policy.yaml` is the cross-service reference; the platform mirror at `platform/helm/genealogy-platform/files/media-protected-delivery-policy.yaml` is byte-identical and enforced by the linter. The E6.1e research policy + E7.1 upload-lifecycle policy + E7.2 malware/metadata policy + E7.3 processing policy mirrors are preserved untouched.

## Security and privacy

- **Tenant isolation**: PASS — every authorization request carries `tenantScopeId` + `assetId` + `actorPseudoId` + `correlationId`; the `MediaTenantScopedId` regex + length cap blocks path-traversal attacks; the `MediaProtectedDelivery.isDnaBucketKey(...)` prefix shield rejects any object key under `dna/`, `dna/match/`, `dna/raw/`, or `dna/consent/`. The `media-service-delivery` NetworkPolicy default-denies ingress + egress; allowed egress is restricted to the E7.4 sandbox allowlist (`apicurio`, `vault-agent`, `openfga`, `audit-service`) + kube-dns. Per `design.md` §11 (binary parser không truy cập Internet, chạy non-root, read-only filesystem và resource quota).
- **Authorization/ABAC**: PASS — `DeliveryOpenFgaPort` + `DeliveryWatermarkPort` + `DeliverySignedUrlPort` are pure ports; the application layer injects the OpenFGA SDK + the watermark worker + the S3 / MinIO signer in the later E7.x / E11.x sub-epics. The contract is closed-set + `deliveryDenyBeforeOpenFgaAndAbac=true` + `dnaBucketAccess=FORBIDDEN` so the adapter cannot silently weaken the guarantee.
- **Secret/PII/DNA leakage**: PASS — `DeliveryAuthorizationRequest` rejects blank / oversized labels + delivery ids + object keys + actor pseudo ids + correlation ids. The linter forbids `credential`, `api[_-]?key`, `private[_-]?key`, `authorization`, `bearer`, `raw[_-]?dna`, `raw[_-]?ssn`, `raw[_-]?passport`, `fastq`, `dna[_-]?raw`, `exif[_-]?gps`, `camera[_-]?serial` outside the `forbiddenPayloadPatterns:` list. `DELIVERY_DNA_BUCKET_FORBIDDEN` + `DeliveryAbacReason.DNA_BUCKET_DENIED` + `DeliveryFailureReason.ABAC_DENY` enforce the closed-set `dnaBucketPrefixes` BEFORE OpenFGA. The `DELIVERY_PSEUDONYM_IN_AUDIT` invariant + the `WatermarkOverlay` actor-pseudo-id embedding enforcement + the `actorPseudoId` length cap (64) + the `correlationId` length cap (128) keep raw identifiers out of audit + watermark payloads. The `media-service-delivery` ExternalSecret references Vault paths; no literal credentials are committed.
- **Dependency/config scan**: PASS — `pnpm check:boundary` clean; `pnpm check:gradle:lock` clean. No new direct dependencies.

## Residual risks

- **OpenFGA SDK + watermark worker + S3 / MinIO signer are scoped for E7.x / E11.x** — the three delivery ports (`DeliveryOpenFgaPort` + `DeliveryWatermarkPort` + `DeliverySignedUrlPort`) are pure interfaces; the actual OpenFGA SDK + libvips / Skia / Chromium watermark HTTP client + S3 / MinIO signed-URL signer land in the worker subproject in the later E7.x / E11.x sub-epics. The E7.4 evidence file does not claim them as DONE; the closed-set policy + the executor's deterministic behaviour are the contract guarantee that the upcoming sub-epics can keep the policy in lockstep. Per `agent-execution.md` §4.4 the chart keeps the workload `contract-only` until the worker subproject lands.
- **Pre-existing umbrella chart issues** — `templates/components/vault/policies-configmap.yaml:21` references an undefined `identity` function and a few Kong YAML templates are missing `---` document-start markers; both errors pre-date E7.4 and are out of scope. The E7.4 templates render cleanly when isolated.
- **Testcontainers IT is scoped for E7.x / E11.x** — the executor is a pure in-memory function; integration tests against the OpenFGA SDK + the watermark worker + the S3 / MinIO signer land in the later sub-epics.
- **Watermark worker payload caps** — `WatermarkOverlay.overlayText` is capped at 64 chars to bound memory + log redaction overhead; longer overlays (e.g. legal notices with a citation URL) would require an ADR supersession.
