# Completion Evidence — E7.5

- Status: DONE
- Completed at: 2026-08-15T22:10:00+07:00
- Scope: Media album + linking — single source-of-truth policy contract for the `Album` aggregate that lets the editor journey organise MediaAsset / MediaVariant objects under named albums with tags, captions, date/place metadata, and cross-service references (Person / Event / Source / Citation / Place / Date). Cross-domain references are stored as OPAQUE ids only (per `design.md` §5.1 — "Không join xuyên service"); the reconciliation Temporal workflow re-resolves references through Kafka events from the publishing services and flags dangling / revoked references. Soft-delete with `softDeleteRetentionDays=365`, LEGAL_HOLD with `objectLockComplianceDays=30` Object Lock COMPLIANCE mode, and an object garbage collector that purges derived artefacts after the retention window. The DNA bucket shield (`dnaBucketPrefixes=[dna/raw, dna/match, dna/consent]`) is enforced here too — the DNA service owns its own delivery path per ADR-E0.5-15 + `privacy-and-legal-gate.md` §5.

## Decisions

- **ADR-E0.5-08 (Avro + Apicurio + BACKWARD evolution): ACCEPTED** — every closed-set vocabulary anchored to the YAML contract; the Java enum values are validated by the linter. Adding a new value requires an ADR supersession.
- **ADR-E0.5-01 (Java 21 toolchain): ACCEPTED** — `services/media-service/build.gradle.kts` applies the `java-conventions` + `service-conventions` plugins (Java 21, Checkstyle, ArchUnit boundary guard).
- **ADR-E0.5-06 (OpenFGA store-per-tenant, p95 ≤ 500 ms): ACCEPTED** — `AlbumOpenFgaPort` is a pure port; the orchestrator calls it with `(tenantScopeId, albumId, actorPseudoId, correlationId)` and refuses to allow the operation if OpenFGA returns DENY. The cross-service reference resolver runs AFTER the OpenFGA verdict per `albumReferencesCheckedBeforeCommit=true`.
- **ADR-E0.5-07 (Reconciliation Temporal workflow): ACCEPTED** — the album reconciliation workflow re-resolves cross-service references every `reconciliationCadenceHours=24`; `ReconciliationReport` is the canonical artifact; `reconciliationOutboxEventRequired=true` + `reconciliationOutboxEventName=gp.media.v1.AlbumReconciliationPurged` wire the outbox event.
- **ADR-E0.5-15 (DNA file formats + consent revocation): ACCEPTED** — `dnaBucketAccess=FORBIDDEN` + `dnaBucketPrefixes=[dna/raw, dna/match, dna/consent]` are enforced in the orchestrator's step 2 BEFORE OpenFGA + the cross-service reference resolver; `AlbumCatalog.isDnaBucketKey(...)` refuses any item pointing into the dna/ prefix set.
- **`albumLinkableAssetStatuses=[DERIVED_READY]` is a hard invariant** — the orchestrator's step 3 enforces `item.derivedReady()` for every item; `derivedReady=false` forces `DENY` with `ALBUM_DERIVED_OBJECT_KEY_NOT_READY`. The E7.3 linkability invariant carries through to E7.5.
- **Cross-service references are OPAQUE ids only** — `crossServiceReferencesAreOpaque=true` + `crossServiceReferencesRequirePublisherResolution=true` + `placeReferenceFormat=PLACE_PSEUDO_ID` + `dateReferenceFormat=DATE_PSEUDO_ID`. The publishing service (genealogy / research / place / date) owns the truth; the reconciliation worker re-resolves through Kafka events. media-service NEVER imports another service's `db/` or `domain/` package.
- **Soft-delete + retention + Object Lock** — `softDeleteRetentionDays=365` + `objectLockComplianceDays=30` + `objectLockComplianceRequiredForLegalHold=true`. The visibility flip to `LEGAL_HOLD` is refused with `ALBUM_VISIBILITY_FORBIDDEN` if the bucket does not support COMPLIANCE-mode Object Lock. The object garbage collector purges derived artefacts after the retention window + skips LEGAL_HOLD albums.
- **BCP-47 caption language** — `captionLanguageIetfBcp47Required=true` + `bcp47LanguageTagPattern=^[a-z]{2,3}(-[A-Za-z]{4})?(-[A-Z]{2}|-[0-9]{3})?$`. The `AlbumItemRequest` compact constructor refuses a caption without a valid BCP-47 tag; the orchestrator re-checks at commit time.
- **Tag normalisation** — `tagNormalizationRule=LOWERCASE_TRIM_DASH`. `AlbumCatalog.normaliseTag(...)` collapses whitespace → single dash, strips leading / trailing dashes, lower-cases. Two callers writing "Family" and "family" hash to the same tag key.
- **Versioning + ETag + If-Match** — `albumVersioningRequired=true` + `albumEtagRequired=true`. The orchestrator bumps `albumVersion` on every write; the `etag` is a hex hash of `albumId:actorPseudoId:issuedAt`. The BFF supplies `If-Match` per `design.md` §7.1.
- **Sandbox egress allowlist** — `sandboxEgressAllowlist=[apicurio, vault-agent, openfga, audit-service, kafka-broker, search-service]`. The reconciliation worker pulls Kafka events from the genealogy / research services but NEVER directly imports their `db/` / `domain/` packages. The Kafka consumer + the search service are sandboxed peer services.
- **Outbox envelope** — `outboxRequiredFields=[eventId, eventType, occurredAt, tenantId, aggregateId, aggregateVersion, traceId]` per `design.md` §7.3. Every reconciliation event emits through the audit hook + the outbox envelope.
- **No cross-service domain import** — the ArchUnit boundary guard (`ServiceBoundaryTest`) blocks accidental coupling to other services; `pnpm check:boundary` clean. The new `services/media-service/.../albums/` package only references `AlbumOpenFgaPort` + `AlbumReferenceResolverPort` ports — never another service's `db/` or `domain/`.
- **No new dependency added** — `services/media-service/build.gradle.kts` keeps the existing `spring-boot-starter-actuator + postgres + flyway + openfeature` baselines + the `archunit-junit5:1.3.0` transitive. No new Maven coordinates.
- **Single source of truth** — the YAML contract under `contracts/media/albums-linking-policy.yaml` is the cross-service reference; the platform mirror at `platform/helm/genealogy-platform/files/albums-linking-policy.yaml` is byte-identical and enforced by the linter. The E6.1e research policy + E7.1 upload-lifecycle policy + E7.2 malware/metadata policy + E7.3 processing policy + E7.4 protected-delivery policy mirrors are preserved untouched.
- **YAML contract is the source of truth** — the 14 closed-set vocabularies + the 2 state machines + the 35 boolean guard rails + the 26 numeric bounds + the 34 invariant reason codes + the 18 audit hooks live in `contracts/media/albums-linking-policy.yaml` and the helm mirror. The Java executor mirrors the contract; the linter enforces it.

## Security and privacy

- **Tenant isolation**: PASS — every authorization request carries `tenantScopeId` + `albumId` + `actorPseudoId` + `correlationId`; the `AlbumCatalogLimits` length caps block path-traversal / oversized label attacks; the `AlbumCatalog.isDnaBucketKey(...)` prefix shield rejects any object key under `dna/`, `dna/match/`, `dna/raw/`, or `dna/consent/`. The reconciliation worker only consumes Kafka events from the publishing services via the closed-set `crossServiceReferencesResolveThrough=[gp.genealogy.v1, gp.research.v1]` allowlist.
- **Authorization/ABAC**: PASS — `AlbumOpenFgaPort` + `AlbumReferenceResolverPort` are pure ports; the application layer injects the OpenFGA SDK + the cross-service reference resolver in the later E7.x / E11.x sub-epics. The contract is closed-set + `onlyDerivedReadyIsLinkable=true` + `dnaBucketAccess=FORBIDDEN` + `crossServiceReferencesAreOpaque=true` so the adapter cannot silently weaken the guarantee.
- **Secret/PII/DNA leakage**: PASS — `AlbumOperationRequest` rejects blank / oversized labels + album ids + actor pseudo ids + correlation ids; `AlbumItemRequest` rejects blank / oversized item ids + derived object keys + captions + tags; `AlbumReferenceRequest` rejects blank / oversized reference pseudo ids. The linter forbids `credential`, `api[_-]?key`, `private[_-]?key`, `authorization`, `bearer`, `raw[_-]?dna`, `raw[_-]?ssn`, `raw[_-]?passport`, `fastq`, `dna[_-]?raw`, `exif[_-]?gps`, `camera[_-]?serial`, `name[_-]?on[_-]?birth`, `social[_-]?security` outside the `forbiddenPayloadPatterns:` list. `ALBUM_DNA_BUCKET_FORBIDDEN` + `dnaBucketPrefixes` enforce the closed-set DNA prefix set BEFORE OpenFGA + reference resolution. The `ALBUM_CAPTION_LANGUAGE_MISSING` + BCP-47 regex compile check force captions to carry a language tag — preventing the silent leak of an untranslated text blob. The `place_pseudo_id` / `date_pseudo_id` format enforces opaque placeholders so raw place names / dates cannot leak through the album metadata.
- **Dependency/config scan**: PASS — `pnpm check:boundary` clean; `pnpm check:gradle:lock` clean. No new direct dependencies.
