## Limitations

- The harness runs in Node 22 + `node:worker_threads`; the
  Worker boundary cost is measured but the JS engine JIT
  profile is not Chromium-on-mid-tier-mobile. The
  recommendation memo flags where the Node numbers are
  likely conservative (SVG/Canvas layout is dominated by
  string building; the real browser render loop is
  faster).
- The bench does not exercise ABAC redaction cost — the
  redaction policy (E3.4) runs server-side and only the
  redacted projection reaches the renderer. E5.3
  re-measures when the projection API is wired.
- The bundle-size proxy is the serialized renderer JS
  output, not the webpack bundle; the real bundle is
  measured by `apps/web/test/perf-budget.test.ts` after
  `next build` once E5.3 lands.
- Accessibility + keyboard scores are heuristics; the
  authoritative audit is Playwright + axe-core in E5.5.
