# apps/web/public

Static assets served verbatim by Next.js from `/`. Per
`design.md` §10.1 the PWA is installable and offline-aware; this
directory holds the install + discovery surface.

Contents:

- `manifest.webmanifest` — PWA manifest consumed by the service
  worker and the install prompt.
- `icons/` — application icons referenced by the manifest.
- `robots.txt` — generated by `apps/web/src/app/robots.ts`; presence
  here is the fallback for environments where Next.js has not built.

Owner: web-app team. Reviewer: Design, Accessibility.
