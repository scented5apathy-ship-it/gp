# docs/ownership

Human-readable ownership documentation. The machine-readable source
of truth is `config/teams.yaml`; this directory explains it.

- `OWNERS.md` — repo-level ownership rules and CODEOWNERS
  walkthrough.
- `team-map.yaml` — narrative mirror of `config/teams.yaml` with
  contact info and on-call rosters (per
  `ownership-catalog.md` §1).

Owner: platform-primary. Reviewers: every team lead in
`config/teams.yaml`.
