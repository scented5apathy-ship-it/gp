# Security CI — Genealogy Platform

This directory contains the configuration for the OSS security CI gate
mandated by `tasks.md` E1.6 and `architecture-decisions.md` ADR-E0.5-13
(§13 CI / registry / Cosign).

Owner: `@genealogy/security` (per `ownership-catalog.md` §6.4).

## Tools

| Tool     | Purpose                              | Image / Binary                         | Config                  |
| -------- | ------------------------------------ | -------------------------------------- | ----------------------- |
| Gitleaks | Secret scanning                      | `ghcr.io/gitleaks/gitleaks:v8.21.2`    | `gitleaks.toml`         |
| Semgrep  | SAST (TS / JS / Java / Helm / YAML)  | `semgrep/semgrep:1.95.0`               | `semgrep/*.yaml`        |
| Trivy    | CVE + IaC + secrets                  | `aquasec/trivy:0.58.1`                 | `trivy/*.yaml`          |
| Syft     | SBOM generation (CycloneDX JSON)     | `anchore/syft:v1.27.0`                 | n/a (CLI flags)         |
| Grype    | SBOM vulnerability mirror (advisory) | `anchore/grype:v0.81.0`                | n/a                     |
| Checkov  | IaC / Helm / Dockerfile / Terraform  | `bridgecrew/checkov:3.2.533`           | `checkov/.checkov.yaml` |
| Cosign   | Image signing + SLSA provenance      | `gcr.io/projectsigstore/cosign:v2.4.1` | n/a                     |

All images are pinned by digest in `images.lock`. Renovate keeps the
digests up to date per `.github/renovate.json` `packageRules[5]`.

## Severity gate

| Scanner       | Blocking severity                | Source                              |
| ------------- | -------------------------------- | ----------------------------------- |
| Gitleaks      | any finding                      | `gitleaks.toml` (`exit-code = 1`)   |
| Semgrep       | ERROR (custom), HIGH+ upstream   | `semgrep scan --error`              |
| Trivy (fs)    | HIGH + CRITICAL                  | `trivy fs --severity HIGH,CRITICAL` |
| Trivy (sbom)  | advisory (no exit)               | rerun with `--exit-code 1` in CI    |
| Grype         | advisory (no exit)               | rerun with `--fail-on high` in CI   |
| Checkov       | any failing check                | `--compact`                         |
| license-check | any AGPL / SSPL / Commons-Clause | `scripts/license-check.mjs`         |

## Running locally

```bash
# Every scanner at once
node scripts/security-ci.mjs all

# Individual scanners
node scripts/security-ci.mjs secrets   # gitleaks
node scripts/security-ci.mjs sast      # semgrep
node scripts/security-ci.mjs vuln      # trivy + grype
node scripts/security-ci.mjs iac       # trivy-IaC + checkov
node scripts/security-ci.mjs sbom      # syft
node scripts/security-ci.mjs license   # license-check
```

The orchestrator requires Docker. Every artefact lands under
`security/artifacts/` (gitignored).

### Cosign

```bash
# Sign an image with the local dev key
node scripts/cosign-sign.mjs sign \
  --image ghcr.io/genealogy/genealogy-service:sha-abcdef0 \
  --sbom security/artifacts/sbom.cdx.json

# Verify in CI / downstream consumers
node scripts/cosign-sign.mjs verify \
  --image ghcr.io/genealogy/genealogy-service:sha-abcdef0
```

The CI workflow sets `COSIGN_OIDC_TOKEN` from the GitHub Actions OIDC
exchange per ADR-E0.5-13 §13; local developers use `--key` with a key
generated by `cosign generate-key-pair`.

## Exceptions

- `.trivyignore` — repo-root file listing known CVEs with owner and
  expiry date. Renewals require an ADR or a security team approval
  per `ownership-catalog.md` §6.4 RACI.
- `security/semgrep/semgrep.local.yaml` — project-specific rules,
  reviewed by the security team on change.
- `security/checkov/exceptions/` — per-check exemptions, required to
  carry an ADR / runbook reference.

## Triage

Every HIGH / CRITICAL finding produces:

1. A JSON / SARIF artefact under `security/artifacts/`.
2. A Renovate PR via Renovate's `vulnerabilityAlerts` integration
   (when the upstream scanner pushes an advisory to the GitHub Advisory
   Database).

The security team owns the SLA: HIGH = 7 days, CRITICAL = 24 hours per
`ownership-catalog.md` §6.4.
